사진을 길게 누르거나 오른쪽 클릭해서 "이미지 주소 복사"한 링크를 붙여 넣어 주세요. 구글 드라이브·드롭박스 공유 링크도 돼요(전체 공개일 때). 사진이 파일 안에 들어가지 않아서 임시저장과 HTML 파일이 훨씬 가벼워져요.

HTML 파일로 저장

HTML 파일로 저장 시에는 이미지 링크로 이미지를 넣어야 파일 크기가 커지지 않습니다. HTML 코드를 다운받아 사용하려면 반드시 링크로 이미지를 추가해 주세요!

링크로 넣은 사진이 엑박(깨진 그림)으로 보이는 이유
  • 사진 주소가 아니라 웹페이지 주소인 경우 — 게시글·핀 주소 말고, 사진을 길게 누르거나 오른쪽 클릭해서 "이미지 주소 복사"한 링크를 넣어 주세요.
  • 사진을 다른 곳에서 못 쓰게 막아 둔 사이트 — 네이버 블로그·카페, 인스타그램, 일부 커뮤니티 사진은 그 사이트 밖에서 열면 엑박이 떠요.
  • 시간이 지나면 사라지는 주소 — 인스타그램·페이스북·디스코드 등의 사진 주소는 며칠 뒤 만료돼서 처음엔 보이다가 나중에 엑박이 될 수 있어요.
  • 비공개이거나 지워진 사진 — 구글 드라이브는 "링크가 있는 모든 사용자"로 공유해야 해요. 원본 사진을 지우면 엑박이 돼요.

확인 방법: 링크를 새 창에 붙여 넣었을 때 사진만 단독으로 뜨면 괜찮아요. 오래 쓸 사진은 imgur, postimages 같은 이미지 호스팅 사이트에 올린 뒤 그 이미지 주소를 쓰는 게 가장 안전해요.

Q&A

1. 이미지 링크로 넣기 후 HTML 파일 다운받았는데 이미지는 안 보이고 엑박 (물음표 표시) 으로 뜨면 어떡하나요?

⤷ 이미지 링크가 실제 이미지 주소가 아니거나 비공개, 외부 접근 차단 상태면 엑박이 뜨니 이미지 우클릭 → "이미지 주소 복사"로 다시 넣거나 imgur 같은 이미지 호스팅 사이트를 사용해 주세요. 구글 드라이브의 경우, 공유 권한이 공개인지 확인 후 링크 넣어주세요~

2. HTML 파일 다운 받았는데 화면 연동이 안 돼요.

⤷ HTML 파일 다운 버튼 중 "전체" 를 누르고 다운 받으셔야 화면끼리 연동이 됩니다.

3. 게시물 사진이 슬라이딩 되지 않아요.

⤷ 클릭하셔야 다음 사진으로 넘어갑니다.

4. 몇몇 브라우저에서 PNG 이미지 저장이 안 되는 오류를 수정했습니다.

⤷ 이후에도 저장이 안 되신다면 추가 제보 부탁드리겠습니다!
