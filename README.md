# 인스타 메이커

인스타그램 화면을 실제 앱 UI 그대로 만들어 PNG로 저장하는 정적 웹 도구입니다.

- **게시물**: 아이디·프로필 사진·인증 배지·위치·공동 게시물, 여러 장 캐러셀(1/3 표시와 점), 비율(4:5, 1:1, 3:4, 1.91:1), 좋아요/댓글/리포스트/공유 숫자, 캡션(#태그·@멘션 강조, "더 보기" 접기)
- **댓글**: 게시물 위에 열린 댓글 시트(반/전체) 또는 시트만, 답글 들여쓰기, 작성자 표시, 고정됨, 작성자가 좋아함, "답글 N개 더 보기"
- **스토리**: 1장 / 2분할 / 3분할 / **4분할** / 6분할 레이아웃, 칸마다 사진 위치·확대 조절, 배경색, 꾸미기 스티커(텍스트 6종 글꼴, 이모지, 멘션, 위치, 해시태그, 링크, 음악, 질문, 사진), 상단 진행 바·하단 메시지 바 (끄면 업로드용 1080×1920 원본)
- **내 계정**: 프로필 화면(게시물/팔로워/팔로잉, 소개, 링크, 프로필 편집 버튼, 하이라이트, 피드 그리드, 하단 탭 바)
- 라이트/다크 모드, 상태 표시줄 시각 변경
- 입력 내용은 브라우저(localStorage)에만 저장됩니다. 서버로 보내지 않습니다.

## 배포 (GitHub Pages)

빌드 과정 없이 파일 그대로 배포됩니다.

1. 저장소 **Settings → Pages**
2. **Source**: `Deploy from a branch`, **Branch**: `main` / `/ (root)` → Save
3. 잠시 후 `https://s2ndrome.github.io/4layout/` 에서 열립니다.

로컬에서 보려면: `python3 -m http.server` 후 `http://localhost:8000`

## 파일

- `index.html` – 편집 화면
- `style.css` – 편집기 + 인스타그램 UI 스타일
- `app.js` – 상태, 미리보기 렌더링, 스토리 드래그/핀치, PNG 저장
- `vendor/html-to-image.js` – DOM → PNG 변환 (MIT, v1.11.11)

인스타그램과 관련 없는 비공식 목업 도구입니다.
